# Q1. 誤り探し｜幻影旅団のルール

- 難易度: おまめ専用
- 形式: 複数選択 (誤っているものをすべて選ぶ。正解の数は示さない)

## 問題
幻影旅団について、次の記述を「誤っている」「正しい」に仕分けてください。(誤っている記述の数は示しません)

## 選択肢
- (a) 結成時のメンバー9名は全員が流星街出身である
- (b) 団員同士の揉め事はコイントスで解決するルールがある
- (c) 旅団は「団長の生存」を最優先する組織である
- (d) シズクは団員の中で唯一クロロに敬語で話す
- (e) 入団の条件は「現役団員を倒す」ことのみである

## 正解
(c)(e)

## 解説
生存の優先順位は団長ではなく「旅団そのもの」。入団は欠員時に団員からの推薦を受ける経路もある。

## 採点
選択集合の完全一致
