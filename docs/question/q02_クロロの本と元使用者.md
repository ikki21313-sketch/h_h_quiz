# Q2. マッチング｜クロロの本と元使用者

- 難易度: おまめ専用
- 形式: 穴埋め・組み合わせ (左の能力ごとに右の元使用者を候補から選ぶ)

## 問題
クロロの本 (盗賊の極意) に収められた能力と、その「元の使用者」を対応させてください。候補には余りがあります。

## 選択肢
| 左 (能力) | 右 (元使用者) |
|---|---|
| 1. 不思議で便利な大風呂敷 | A. 梟 |
| 2. 天使の自動筆記 | B. ネオン＝ノストラード |
| 3. 番いの破壊者 | C. 流星街の長老 |
| 4. 携帯する他人の運命 | D. シャルナーク |
| 5. 神の左手悪魔の右手 | E. コルトピ |
| 6. 密室遊魚 | F. 作中で未判明 |
|  | G. マチ |

## 正解
1-A, 2-B, 3-C, 4-D, 5-E, 6-F

## 採点
6 ペア完全一致

## 根拠
Wikipedia「クロロ＝ルシルフル」項の各能力「元使用者」欄 ★★★

## 実装メモ
右側の候補 A〜G は全行で共通。余り (G) を必ず残す。
