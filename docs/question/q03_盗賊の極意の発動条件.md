# Q3. 複数空欄｜盗賊の極意の発動条件

- 難易度: おまめ専用
- 形式: 穴埋め・組み合わせ (空欄ごとに候補から選ぶ)

## 問題
次の空欄をすべて埋めてください。

> 相手の能力を盗むには、（①）以内に「相手の念能力を実際に（②）」「能力について相手に（③）て答えを得る」「本に相手の（④）を押させる」の 3 条件を満たす必要がある。

## 選択肢
- ①: 30分 / 1時間 / 3時間 / 24時間
- ②: 見る / 受ける / 聞く / 触れる
- ③: 尋ね / 命じ / 書かせ / 念じ
- ④: 手形 / 署名 / 血 / 髪

## 正解
①1時間 ②見る ③尋ね ④手形

## 採点
各空欄の一致

## 根拠
Wikipedia「クロロ＝ルシルフル」項 ★★★

## 実装メモ
元は記述式 (「手形」は掌／手のひらも可)。候補選択に変えたため表記ゆれ対応は不要。
