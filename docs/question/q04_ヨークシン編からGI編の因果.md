# Q4. 並べ替え｜ヨークシン編〜G.I 編の因果

- 難易度: おまめ専用
- 形式: 並べ替え (5 項目)

## 問題
次の出来事を起きた順に並べてください。

## 選択肢
- (ア) パクノダが記憶弾を使って死亡する
- (イ) ウボォーギンがクラピカに殺害される
- (ウ) クロロがネオンの念能力を盗む
- (エ) クロロが念能力を封印される
- (オ) ヒソカが除念師を探すためグリードアイランドに入る

## 正解
イ → ウ → エ → ア → オ

## 採点
順列の完全一致

## 根拠
Wikipedia「幻影旅団」活動史および各人物項。(イ) と (ウ) の前後は作中日付 (9月2日／9月3日) の記憶に基づく ★★☆

## 実装メモ
(イ) → (ウ) の前後だけは原作 9〜12 巻で確認推奨。
