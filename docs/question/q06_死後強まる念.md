# Q6. 集合回答｜死後強まる念

- 難易度: おまめ専用
- 形式: 複数選択 (候補から 3 つ選ぶ)

## 問題
作中で「術者の死後に念が強まる」性質によって死後に発動した能力を 3 つ、「該当する」の箱に入れてください (順不同)。

## 選択肢
- 伸縮自在の愛 (バンジーガム)
- 黒子舞想 (テレプシコーラ)
- 番いの破壊者 (サンアンドムーン)
- 百万回生きた猫 (ネコノナマエ)
- 神速 (カンムル)
- 絶対時間 (エンペラータイム)
- 薄っぺらな嘘 (ドッキリテクスチャー)
- 転校生 (コンバートハンズ)

## 正解
上 4 つのうち任意の 3 つ: 伸縮自在の愛 (バンジーガム) / 黒子舞想 (テレプシコーラ) / 番いの破壊者 (サンアンドムーン) / 百万回生きた猫 (ネコノナマエ)

## 採点
選んだ 3 つがすべて正解候補に含まれていれば正解

## 解説
該当するのは伸縮自在の愛、黒子舞想、番いの破壊者、百万回生きた猫の4つ。このうち3つを選べば正解です。

## 根拠
Wikipedia「ヒソカ」「ネフェルピトー」「クロロ」「カミーラ」各項 ★★★

## 実装メモ
元は記述式 (能力名で 3 つ答える)。候補選択に変え、ダミー 4 つを追加。
ちょうど 3 つ選ぶまで決定できない。
