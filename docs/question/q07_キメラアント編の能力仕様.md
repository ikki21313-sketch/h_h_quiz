# Q7. 誤り探し｜キメラ＝アント編の能力仕様

- 難易度: おまめ専用
- 形式: 複数選択 (誤っているものをすべて選ぶ。正解の数は示さない)

## 問題
キメラ＝アント編の能力仕様について、次の記述を「誤っている」「正しい」に仕分けてください。(誤っている記述の数は示しません)

## 選択肢
- (a) ハコワレの利息は対象者が 100m 以上離れるとカウントが止まる
- (b) 神の不在証明は「円」による感知も無効化する
- (c) 玩具修理者は死者を生き返らせることができる
- (d) ヂートゥの念空間は一度解除されると能力自体を失う
- (e) 謝債発行機による能力のレンタルは 1 回 1 時間である
- (f) 卵男 (ミサイルマン) のミサイルは命中率 100% で、直撃で致命傷を与える

## 正解
(c)(f)

## 解説
玩具修理者は死体を腐敗しないよう作り直すのみで蘇生はできない。卵男のミサイル自体に殺傷力はなく、植え付けられる黒百足が反抗心を糧に成長して殺す。

## 採点
選択集合の完全一致
