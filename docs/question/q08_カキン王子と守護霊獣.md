# Q8. マッチング｜カキン王子と守護霊獣・念能力

- 難易度: おまめ専用
- 形式: 穴埋め・組み合わせ (左の王子ごとに右の特徴を候補から選ぶ)

## 問題
左の王子と右の特徴を対応させてください。右側に余りが 1 つあります。

## 選択肢
| 左 (王子) | 右 (特徴) |
|---|---|
| 1. ベンジャミン | A. 死んだ私設兵の念能力を継承する |
| 2. カミーラ | B. 本人の死をトリガーに黒猫の念獣が出現し蘇生する |
| 3. ツェリードニヒ | C. 絶の状態で 10 秒先の未来を視る |
| 4. サレサレ | D. ガスを吸った者を信奉者にし感染拡大する |
| 5. ハルケンブルグ | E. 羽で刻印した者をチーム化しオーラを増幅する |
| 6. フウゲツ | F. 1 日 1 回使える空間移動の扉 |
|  | G. 1 日 1 枚、数字付きコインを吐き出す |

## 正解
1-A, 2-B, 3-C, 4-D, 5-E, 6-F (G はチョウライ)

## 採点
6 ペア完全一致

## 根拠
Wikipedia「カキン王子」各項 ★★★

## 実装メモ
右側の候補 A〜G は全行で共通。余り (G) を必ず残す。
