# Q9. 誤り箇所の選択｜ナニカのルール

- 難易度: おまめ専用
- 形式: 4択 (本文中の破線部から誤っている箇所を選ぶ。選択肢は並べ替えない)

## 問題
以下の文章のうち、誤っている箇所を選択してください。

> アルカの「おねだり」を（a）[3]回連続で叶えると、どんな願いでも 1 つ叶えられる。逆におねだりを(b)[3]回連続で断ると、断った本人とその人物が最も愛する人物が死ぬ。ただしキルアだけは「(c)[命令]」することで代償なしに願いを叶えられる。

## 選択肢
- (a)
- (b)
- (c)
- すべて誤り
- 誤りはない
- 誤っている箇所はない

## 正解
(b)

## 採点
誤っている箇所を選択
