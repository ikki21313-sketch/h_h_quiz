# Q10. マッチング｜クラピカの鎖と錘の形

- 難易度: おまめ専用
- 形式: 穴埋め・組み合わせ (指ごとに錘の形を候補から選ぶ)

## 問題
各指の鎖と、先端の錘の形を対応させてください。

## 選択肢
| 指 | 錘の形 |
|---|---|
| 1. 親指 (癒す鎖) | A. 注射器 |
| 2. 人差し指 (奪う鎖) | B. 刃 |
| 3. 中指 (束縛する鎖) | C. 十字架 |
| 4. 薬指 (導く鎖) | D. 鍵爪 |
| 5. 小指 (律する鎖) | E. 球 |

## 正解
1-C, 2-A, 3-D, 4-E, 5-B

## 採点
5 ペア完全一致 (5×5＝120 通りなので消去法が効きにくい)

## 根拠
Wikipedia「クラピカ」各鎖の項 ★★★

## 実装メモ
右側の候補 A〜E は全行で共通。余りなし。
