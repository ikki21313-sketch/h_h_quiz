# Q11. 並べ替え｜選挙編の出来事

- 難易度: おまめ専用
- 形式: 並べ替え (5 項目)

## 問題
会長選挙編の出来事を、起きた順に並べてください。

## 選択肢
- (a) ネテロの遺言により十二支んが招集される
- (b) 第 1 回投票が行われる
- (c) キルアがアルカを連れてゾルディック家を出る
- (d) ナニカの力でゴンが回復する
- (e) パリストンが当選し、会長を辞任する
(正解の順で記載)

## 正解
(a) → (b) → (c) → (d) → (e)

## 解説
ゴンの回復は最終投票の前。パリストンは当選直後に辞任し、チードルが会長になった。
