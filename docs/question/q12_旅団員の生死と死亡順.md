# Q12. 仕分け＋並べ替え｜旅団員の生死と死亡順

- 難易度: おまめ専用
- 形式: 仕分け＋並べ替え (「死亡した」「死んでいない」の箱に全カードを仕分け、「死亡した」は順番も答える)

## 問題
次の幻影旅団員を「死亡した」「死んでいない」に仕分けてください。「死亡した」の箱は、作中で死亡した順に上から並べてください。

## 選択肢
- (a) クロロ
- (b) ノブナガ
- (c) フェイタン
- (d) マチ
- (e) カルト
- (f) フィンクス
- (g) シャルナーク
- (h) フランクリン
- (i) シズク
- (j) パクノダ
- (k) ボノレノフ
- (l) ウボォーギン
- (m) コルトピ
- (n) イルミ

## 正解
「死亡した」(この順): (l) → (j) → (m) → (g)
「死んでいない」: 残りすべて

## 解説
ウボォーギン (ヨークシン編) → パクノダ (ヨークシン編) → コルトピ → シャルナーク (クロロ対ヒソカ戦の直後、コルトピが先)。元 4 番のヒソカは死亡後に蘇生しているため除外。生死は連載の進行で変わりうる。
