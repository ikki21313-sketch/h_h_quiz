# Q15. 穴埋め・組み合わせ｜十二支んの姓

- 難易度: おまめ専用
- 形式: 穴埋め・組み合わせ (共通候補を解答欄へドラッグ。候補は単一使用)

## 問題
ハンター十二支んのメンバーについて、姓と名を対応させてください。候補には余りがあります。

## 選択肢
| 解答欄 | 正解 |
|---|---|
| ヒル | パリストン |
| ヨークシャー | チードル |
| ナナ | ミザイストム |
| ギガンテ | ボトバイ |
| コバヤカワ | サッチョウ |

候補 (共通): パリストン / チードル / ミザイストム / ボトバイ / サッチョウ / ジン / カンザイ

## 正解
ヒル-パリストン, ヨークシャー-チードル, ナナ-ミザイストム, ギガンテ-ボトバイ, コバヤカワ-サッチョウ

## 解説
パリストン＝ヒル、チードル＝ヨークシャー、ミザイストム＝ナナ、ボトバイ＝ギガンテ、サッチョウ＝コバヤカワ。ジンの姓はフリークス。
