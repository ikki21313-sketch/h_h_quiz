# Q17. 仕分け｜ゾルディック家の執事

- 難易度: おまめ専用
- 形式: 仕分け (「執事である」「執事ではない」の箱に全カードを仕分ける)

## 問題
次のうち、ゾルディック家の執事である人物を仕分けてください。

## 選択肢
- (a) ゴトー
- (b) カナリア
- (c) ツボネ
- (d) アマネ
- (e) ゼブロ
- (f) ヤスハ
- (g) キキョウ
- (h) ヒシタ

## 正解
「執事である」: (a), (b), (c), (d) (h)

## 解説
カナリアは見習い執事、アマネはツボネの孫で執事。ヤスハはナニカに億万長者を願った人。ヒシタはイルミに針人間にされた人。ゼブロは試しの門の門番 (使用人)、キキョウはゾルディック家の家族。
