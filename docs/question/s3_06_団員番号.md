# s3_06. 穴埋め・組み合わせ｜団員番号

- 難易度: 三ツ星
- 形式: 穴埋め・組み合わせ (共通候補を解答欄へドラッグ。候補は単一使用)

## 問題
幻影旅団の団員番号に対応する団員を選んでください。候補には余りがあります。

## 選択肢
| 解答欄 | 正解 |
|---|---|
| 0 番 | クロロ |
| 1 番 | ノブナガ |
| 3 番 | マチ |
| 8 番 | シズク |
| 11 番 | ウボォーギン |

候補 (共通): クロロ / ノブナガ / マチ / シズク / ウボォーギン / フェイタン / パクノダ

## 正解
0 番-クロロ, 1 番-ノブナガ, 3 番-マチ, 8 番-シズク, 11 番-ウボォーギン

## 解説
フェイタンは 2 番、パクノダは 9 番。
