# s3_12. 穴埋め・組み合わせ｜念系統と人物

- 難易度: 三ツ星
- 形式: 穴埋め・組み合わせ (共通候補を解答欄へドラッグ。候補は単一使用)

## 問題
念の六性系統と、その系統に属する人物を対応させてください。

## 選択肢
| 解答欄 | 正解 |
|---|---|
| 強化系 | ゴン |
| 変化系 | キルア |
| 具現化系 | クラピカ |
| 放出系 | レオリオ |
| 操作系 | シャルナーク |
| 特質系 | クロロ |

候補 (共通): ゴン / キルア / クラピカ / レオリオ / シャルナーク / クロロ

## 正解
強化系-ゴン, 変化系-キルア, 具現化系-クラピカ, 放出系-レオリオ, 操作系-シャルナーク, 特質系-クロロ

## 解説
クラピカは緋の眼の状態では特質系になる。
